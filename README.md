# Reduced-Parameter Water Quality Index (WQI) Prediction

## 🚀 Live Demo

[Click here to use the live WQI Prediction App](https://wqireducedmodel-hee8bndumrhsqzmtlheblu.streamlit.app/)

A Streamlit machine-learning application that explores whether a smaller set of water-quality measurements can predict a Water Quality Index (WQI).

> **Important:** The current app generates synthetic river data and trains its Random Forest models on that simulated data. The reported performance is not validation on real river measurements.

## Research question

Can reduced-parameter monitoring provide reliable WQI prediction for data-scarce river systems?

## Project overview

The app lets a user choose between three feature sets:

- **3 parameters:** pH, BOD, total coliform
- **4 parameters:** pH, dissolved oxygen (DO), BOD, total coliform
- **7 parameters:** temperature, pH, DO, BOD, conductivity, nitrate, total coliform

The app trains a Random Forest regressor for each selected feature set and predicts a WQI value from user-entered measurements. It then displays a water-quality class.

## Current data and model

- Data source for the current app run: synthetic/simulated data generated by `wqi_reduced_model.py`
- App training data: 40 stations × 150 readings per station (6,000 rows), as configured in `app.py`
- Model: `RandomForestRegressor`
- App model settings: 200 trees, `min_samples_leaf=2`, `random_state=0`
- Model training happens when the app starts; Streamlit caches the trained models during the running session.

The project presentation/report may contain results from a separate simulated-data experiment. Do not assume those metrics exactly describe this app's current training run unless you have rerun and verified the evaluation.

## Run locally

Use Python installed on your computer. From the project folder, run:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Streamlit will print a local URL, usually `http://localhost:8501`.

## Deploy on Streamlit Community Cloud

1. Push the required project files to a GitHub repository.
2. Open [Streamlit Community Cloud](https://share.streamlit.io/).
3. Connect your GitHub account and create a new app.
4. Select the repository and branch.
5. Set the main file path to `app.py`.
6. Deploy and test the public app.

Make sure `app.py`, `wqi_reduced_model.py`, and `requirements.txt` are committed to GitHub. Include any other files that the app actually reads at runtime.

## Evaluation metrics in the project report

The supplied report describes a simulated-data experiment and reports R², RMSE, and WQI-class accuracy. Those results should be described as simulation-based. Real-world performance remains unverified until the pipeline is evaluated on real, appropriately mapped and cleaned river-monitoring data.

## Limitations

- The current app uses synthetic rather than real CPCB river observations.
- The WQI target is calculated from parameters related to the model inputs, so high predictive scores on simulated data may partly reflect how the target was constructed.
- The simulator's parameter relationships may be simpler than relationships found in real rivers.
- The app should not be used for regulatory decisions, public-health decisions, or official water-quality reporting without suitable validation.
